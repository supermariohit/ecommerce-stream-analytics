# ecommerce-stream-analytics

Проект потоковой аналитики заказов интернет-магазина.

## Предпросмотр генератора

Из корня репозитория запустите одну тестовую пачку заказов. Нужен Python 3.10 или новее.

```sh
python -m generator --batch-size 5 --seed 42
```

Каждый заказ выводится отдельной строкой JSON. Предпросмотр использует несколько товаров и покупателей из начального наполнения ClickHouse и работает без подключения к базе. Город берётся из профиля покупателя, категория и цена — из карточки товара, сумма округляется до копеек.

Размер пачки и начальное состояние генератора можно задать через `BATCH_SIZE` и `SEED`. Аргументы командной строки имеют приоритет. При одинаковом `SEED` содержимое тестовой пачки повторяется, а UUID и время создаются заново.
